# 🐾 宠物大冒险 - Pet Adventure

一款移动端优先的抓宠收集页游，纯前端实现，无需下载安装即可畅玩！

## 🎮 游戏特色

- **25种独特宠物**：火、水、草、电、土、暗6大属性，每种都有独特外形和技能
- **回合制战斗系统**：普攻、技能、道具、逃跑多种选择，属性相克策略丰富
- **宠物进化系统**：宠物达到一定等级可进化，解锁更强形态和技能
- **地图探索**：5个不同区域（草原、森林、山洞、湖泊、火山），各有特色宠物
- **训练师挑战**：击败5位强力训练师，获得丰厚奖励
- **宠物图鉴**：记录已收集的宠物，完成度显示
- **道具商店**：购买精灵球和回复道具

## 🎯 游戏玩法

### 1. 探索地图
- 点击「探索地图」选择想要前往的区域
- 不同区域有不同的野生宠物分布
- 高级区域需要达到一定等级才能进入

### 2. 捕捉宠物
- 在探索中遇到野生宠物后会进入战斗
- 使用技能削弱野生宠物的HP
- HP越低，捕捉成功率越高
- 使用更高级的精灵球可提高捕捉率

### 3. 回合制战斗
- **普通攻击**：无消耗但威力较低
- **使用技能**：消耗PP但威力更强
- **使用道具**：回复HP或投掷精灵球
- **切换宠物**：更换出战宠物
- **逃跑**：逃离野生宠物战斗

### 4. 属性相克
- 🔥 火 > 🌿 草
- 💧 水 > 🔥 火
- 🌿 草 > 💧 水
- ⚡ 电 > 💧 水
- 🪨 土 > ⚡ 电
- 🌑 暗 > 🌑 暗

### 5. 宠物成长
- 战斗胜利获得经验值
- 累积足够经验值升级
- 升级提升属性和学习新技能
- 达到特定等级触发进化

### 6. 挑战训练师
- 点击「挑战训练师」选择对手
- 击败训练师获得大量金币奖励
- 训练师会派出多只宠物进行车轮战

## 🛠️ 技术实现

- **纯前端实现**：HTML5 + CSS3 + JavaScript
- **数据持久化**：localStorage 存档
- **响应式设计**：移动端优先，适配各种屏幕
- **PWA支持**：可添加到主屏幕，离线运行
- **图形资源**：使用 Emoji 和 CSS 绘制，无需外部图片
